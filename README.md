\# Wallet



Small Kotlin practice project modelling a basic digital-credential wallet.



The project defines credentials, claims, presentation requests and presentation plans for selective disclosure.



\## Features



\* Model wallet credentials

\* Model selectively disclosable claims

\* Define presentation requests

\* Check trusted issuers

\* Check credential expiry

\* Track missing, expired or non-disclosable claims



\## Tech stack



\* Kotlin

\* Gradle

\* JUnit 5



\## Run tests



```cmd

gradlew test

```



\## What this project demonstrates



\* Kotlin data classes

\* simple domain modelling

\* credential and claim handling

\* selective-disclosure logic

\* basic validation flow
